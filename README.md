# 🚁 Drone Forte – Futuro Sustentável

## 📖 Sobre o Projeto

O **Drone Forte – Futuro Sustentável** é um projeto desenvolvido para o **Agrinho 2026**, com o objetivo de demonstrar como a tecnologia pode contribuir para uma agricultura mais eficiente e sustentável.

O site apresenta informações sobre drones agrícolas, seus benefícios para o campo, formas de economizar recursos naturais e um mini game interativo para tornar o aprendizado mais divertido.

---

## 🎯 Objetivos

* Mostrar a importância da tecnologia na agricultura.
* Explicar como os drones agrícolas auxiliam os produtores rurais.
* Incentivar práticas sustentáveis no campo.
* Demonstrar os benefícios da agricultura de precisão.
* Promover a conscientização sobre o uso responsável dos recursos naturais.

---

## 🚁 O que são Drones Agrícolas?

Drones agrícolas são aeronaves não tripuladas utilizadas para monitorar plantações, identificar problemas, coletar dados e auxiliar na tomada de decisões dos produtores rurais.

Essas tecnologias permitem uma agricultura mais moderna, eficiente e sustentável.

---

## 🌱 Benefícios dos Drones

* Monitoramento rápido das plantações.
* Economia de água.
* Redução do desperdício de insumos.
* Identificação precoce de pragas e doenças.
* Maior produtividade.
* Menor impacto ambiental.
* Agricultura de precisão.

---

## 💧 Simulador de Economia

O site possui um simulador onde o usuário informa a quantidade de hectares da propriedade.

O sistema calcula uma estimativa de economia utilizando a fórmula:

Economia = Hectares × 50

O resultado é exibido instantaneamente utilizando JavaScript.

## 🧠 Quiz Interativo

O projeto contém um quiz educativo sobre agricultura sustentável e drones agrícolas.

O usuário recebe feedback imediato ao responder as perguntas.

## 📸 Galeria

## 🎮 Mini Game Drone Forte

O projeto inclui um jogo interativo onde:

* O jogador controla um drone 🚁.
* Plantas 🌱 aparecem na tela.
* O jogador deve atirar para ganhar pontos.
* Existe sistema de pontuação.
* Existe sistema de recorde salvo no navegador.

### Controles

* ⬅️ Seta Esquerda: mover o drone.
* ➡️ Seta Direita: mover o drone.
* Espaço: atirar.
